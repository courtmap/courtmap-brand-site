# CourtMap brand book

The visual brand for **CourtMap**, the racquet-sports community app by Deuce Labs Inc. Logo, colour, typography, voice, imagery, motion, and how the brand shows up in the app, on social, in merch and out of home.

**Your court. Your crew.**

Live site: https://courtmap.github.io/courtmap-brand-site/

## Contents

- `index.html`: the brand book (a single static page served with GitHub Pages)
- `images/`: photography (AI-generated with Gemini) and app screens
- `illustrations/`: system-message illustrations, light and dark
- `favicon.svg`, `og.jpg`: browser icon and link-preview image

## Notes

- The @courtmap social handle is a placeholder until it's confirmed on each platform.
- Search engines are asked not to index this site (`robots.txt` and a `noindex` meta tag). Anyone with the link can still view it.
